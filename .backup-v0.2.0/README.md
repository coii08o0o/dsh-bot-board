# Bot 看板（dsh-bot-board）

给 DS Bot 加一块浮动的实时看板，专为「派完活盯进度」设计：**每个 Bot 现在在干什么、卡在哪一步、谁给谁派了活、群聊里谁在说话**，一眼看完，不用逐个点开会话。

这是一个 DSH 插件，配合 [DS Bot](https://github.com/Fei2411/DeepSeek-Bot)（包名 `ds-bot`）使用。它不改 DS Bot 的源码，只读它已有的接口和本地数据。

## 它显示什么

整体是**一间 Bot 教室**：奶油色房间（#FAF7F1），顶部一行图例（干活=绿、等你=黄、卡住=红、闲着=灰、干完=青），下面是 9 个工位（3×3，窄窗口自动变 2 列，可滚动）。每个工位从左到右是：椅子 + 木桌（桌上显示器、状态灯、桌面道具），桌后坐着一个圆圆的团子 Bot，工位下方是 Bot 名。

- **状态一眼读**：状态灯（5px 圆点，图例五色）+ 显示器屏色（干活/等你=浅蓝带 3 道小条；卡住=灰底红条；闲着=灰白空屏；干完=浅绿带对勾）+ 团子的表情动作。
- **卡住的原因**：hover 工位看 title（`Bot 名 · 状态 · 具体动作`），「等你审批：Bash」「报错：模型超时」「等数学交活」一行说清楚。
- **派活交接完成**：接收方进入「干完」7 秒（眯眯眼 + 挥手），同时 2 秒小纸条飞到它桌上。
- **点工位直接跳到那个 Bot 的聊天**，顺着就问。

## 提醒

- 只在「等你审批/回答」和「报错/中断」时弹系统通知，其他情况只变色，不打扰。
- 同一件事只弹一次；新的事才会再弹。
- 面板收起来时，胶囊上会带「N 忙 · N 待 · N 错 · N 等」的计数。

## 交互

- **拖动标题栏**可以把面板移到任意位置，位置记住。
- **拖右下角**可以调面板大小（默认 560×420，最小 420×320，最大 980×700），大小记住。
- **× 收起**成右下角一颗胶囊（N 忙 N 待 N 错），再点展开。
- **点工位** 跳转到那个 Bot 的聊天。

## 数据从哪来

| 数据 | 来源 |
|---|---|
| 每个 Bot 的实时状态、当前工具、审批与提问 | DS Bot 自己的 `POST api/bot`（`endpoint: "state"`），1.5 秒一次 |
| 派活记录（from/to/open/results） | 宿主侧读 `~/.dsh/bot/state.json`，缓存在内存里，按文件时间戳失效 |
| 群聊成员与最近消息 | 同上 |
| 报错 | 宿主侧订阅 DSH 的 `agent/error` 事件，按会话映射回 Bot，保留 15 分钟 |

只读取，不写任何文件，不改 DS Bot 的数据。

## 团子与工位（手绘 SVG，无素材）

小人是 **Grok Bot / OpenAI Dots 那种圆圆的团子**，不是人形：一个大圆身体（r≈26，占身高 70%+）+ 浅色脸盘（r≈18）+ 胶囊眼睛（5×9，#2C2C2A）+ 8px 弧线嘴 + 腮红（opacity .3）+ 两侧各一只小圆手（r≈4），没有腿。全部平涂单色、无渐变无重阴影，只在脚下留一圈 6% 的地面影。全部手绘 SVG，无图片素材、无外链。

- **9 个团子 = 9 个主色 + 一个头饰 + 一个桌道具**（按 Bot 名固定，刷新不换人）：Chief 蓝+皇冠+小旗、Researcher 粉+眼镜+放大镜、班主任 橙+红蝴蝶结+教鞭、数学 紫+眼镜+算盘、物理 青+耳机+闪电、化学 绿+帽子+烧瓶、生物 黄绿+发芽帽+叶子、语文 红+米色蝴蝶结+书、英语 橙红+耳机+话筒。
- **表情按状态**：干活=正常眼 + 3 秒眨眼 + 小手敲桌面；等你=正常眼 + O 形嘴 + 挥手；卡住=眯眼（6px）+ 撇嘴；干完=眯眯笑眼 + 挥手；闲着=正常眼 + 6 秒慢眨眼。
- **动画**：呼吸（身体 scale 1↔1.02，2.6s）、眨眼、敲手、挥手、飞纸条，全部 CSS keyframes；离散动作一律 `step-end` 逐格跳（不滑动），呼吸用平滑 ease-in-out；`prefers-reduced-motion` 块排在所有生成规则之后，开了就全停。

## 安装

插件目录就是本仓库，安装分两步：

1. 在 profile 的 `package.json` 里登记（`~/.dsh/profiles/desktop/package.json`）：

```json
{
  "dependencies": {
    "dsh-bot-board": "file:/Users/admin/Documents/dsh-bot-board"
  },
  "dsh": {
    "profile": {
      "bundles": ["...", "dsh-bot-board"]
    }
  }
}
```

2. 建立依赖链接（本机网络不通时 pnpm 会卡在 GitHub 依赖上，软链最稳）：

```sh
ln -sfn ~/Documents/dsh-bot-board ~/.dsh/profiles/desktop/node_modules/dsh-bot-board
```

3. 完全退出 DeepSeek Harness 再打开，右下角出现「Bot 看板」面板。

## 已踩过的坑（给下次写插件的人）

- `connection.fetch.register` 的 `path` 必须**带前导斜杠**（`/api/bot-board`），不带斜杠会 404；路由是**精确路径名匹配**，不是前缀。
- 客户端 bundle 的 `__ModuleLoader__.load({id})` 里 id 必须等于包名，改名后不重打包会静默不加载。
- 面板挂在 `shell.overlay` 插槽，order 取 500 以上，避开 ds-bot 的 50/55/60。
- 桌面端改完插件必须**整个退出重开**；`osascript quit` 会触发系统自动化权限弹窗，直接 `killall -9 "DeepSeek Harness"` 最干净。

## 已知边界

- 面板常驻所有会话，不只在 DS Bot 里。
- 群聊只显示最近 12 条；派活只显示 `state.json` 里还留着的（DS Bot 读走结果后会删记录）。
- 报错只能抓到 DSH 的 `agent/error` 事件能覆盖的（模型/工具步骤失败）；网络层中断另说。
- DS Bot 升级后如果改了 `api/bot` 的字段，看板需要跟着调整。

## 卸载

从 profile 的 `bundles` 和 `dependencies` 里删掉 `dsh-bot-board`，删掉软链，重启。
